ลากโฟลเดอร์เข้า Codex แล้ววางข้อความนี้ในแชต

03
คุยกับผู้ช่วยใน Codex

เลือกโหมด แล้วส่งไอเดีย รูป และข้อมูลตามที่ผู้ช่วยถาม

ผู้ช่วยคนเดียว ทำได้ 3 โหมด

เลือกสิ่งที่อยากเล่า แล้วให้ผู้ช่วยจัดการต่อ

1

สร้างตัวตน

คำคม ความรู้ เรื่องเล่า นิทาน เริ่มด้วยไอเดียหรือ Prompt จาก Toolkit 1

2

ขายของ

เล่าปัญหา ประโยชน์ และมุมขาย ใช้รูปสินค้าและคนขายตามที่คุณเลือก

3

ขายของแนวบอกโปร

โชว์สินค้า บอกราคา เลือกสถานที่ เลือกเห็นเฉพาะมือหรือมีคนขายได้

คุยจบ รับ Preset ไปใช้ใน KVID

นำเข้าไฟล์ preset JSON แล้วเลือก Meta AI ก่อนเริ่มสร้างวิดีโอ เก็บไฟล์ work JSON ไว้แก้งานหรือขยายเรื่องต่อ โหมดขายมีไฟล์ลิงก์สินค้าให้ด้วย

ถ้าเชื่อม Shopee MCP แล้ว สามารถให้ผู้ช่วยค้นสินค้าได้ หรือส่งรูปและข้อมูลสินค้าเองก็ได้ หากต้องการลิงก์ Affiliate ให้สั่ง “แปลงลิงก์ Aff ให้ด้วย”

ต้องเตรียมอะไร และอัปเดตอย่างไร?

ใช้บัญชี Codex ของคุณเอง ไม่ต้องลงทะเบียนชื่อหรือเบอร์โทรกับผู้ช่วยชุดนี้ ผู้ช่วยจะถามข้อมูลที่จำเป็นก่อนทำงาน นักเรียนไม่ต้องเขียน JSON เอง

ตอนประกอบไฟล์ ผู้ช่วยใช้ Python 3 ที่รันได้ในสภาพแวดล้อมของคุณ หากยังไม่มีจะแจ้งสิ่งที่ต้องเตรียม ชุดดาวน์โหลดไม่มี EXE หรือ DLL แนบมา

เวอร์ชันปัจจุบันคือ เวอร์ชัน 1 เมื่อมีอัปเดตให้ดาวน์โหลดและแนบโฟลเดอร์รุ่นใหม่จากหน้านี้ ชุดโฟลเดอร์ไม่ได้อัปเดตตัวเอง
