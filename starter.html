📦 ดาวน์โหลด Starter
ไฟล์ zip เล็กมาก โหลดได้ทันที · แตกไฟล์แล้วได้โฟลเดอร์ starter

① ต้องมีก่อน 3 อย่าง

🤖 Codex (ChatGPT) ติดตั้งและล็อกอินแล้ว ที่เรียนไปใน EP9 🟢 Node.js ติดตั้งครั้งเดียว (กด Next จนจบ) nodejs.org → ▲ บัญชี Vercel ฟรี สมัครด้วยอีเมล vercel.com →

② ติดตั้ง 3 ขั้น

  1. แตกไฟล์ zip แล้ววางโฟลเดอร์ starter ไว้บน Desktop
  2. เปิดโฟลเดอร์ starter → คลิกขวาที่ว่าง → Open in Terminal (หรือเปิด PowerShell แล้ว cd เข้าไป)
  3. พิมพ์ codex กด Enter · Codex จะอ่านกติกาในโฟลเดอร์เองอัตโนมัติ ไม่ต้องอธิบายอะไร

ครั้งแรกพิมพ์ ติดตั้งเครื่องมือในโฟลเดอร์ tools ให้หน่อย รอ 20 วินาที แล้วเริ่มใช้ได้

④ ได้อะไรออกมา

  • ไฟล์ PDF สินค้าใน products/ พร้อมขาย
  • เว็บ 2 หน้า: หน้าตัวอย่าง (มีลายน้ำ ส่งให้ลูกค้าดูก่อนซื้อ) และ หน้าโหลด ต่อโปร
